# Türkiye Cumhuriyeti Kedi Meclisi Oturum Simülatörü

> **Resmî uyarı:** Bu depo şaka değildir. Şaka gibi durur. Yine de şaka değildir.

Bu yazılım, ev içi egemenliğin en köklü kurumunu — yani **Kedi Meclisi**'ni — terminal ortamında yeniden kurar. 
Amaç, yatak üstü egemenliğini kodla belgelemektir.

## Neden vardır?

Çünkü:

1. İnsan meclisleri çok geç uyanır.
2. Kediler zaten yasa çıkarıyor, sadece tutanak tutulmuyordu.
3. Lazer noktası hâlâ denetimsiz bir kamu kaynağıdır.

## Kurulum

```bash
git clone https://github.com/Tentivory/kedi-meclisi-oturum-simulatoru.git
cd kedi-meclisi-oturum-simulatoru
python3 meclis.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz sabır yeter.  
Sabır yoksa kedi zaten sizi yönetiyordur.

## Örnek çıktı

Program üç yasa tasarısını rastgele görüşür, miyavlarla oylar ve tutanak basar.  
Kararlar bağlayıcıdır. İtiraz kuyruk sallamakla yapılır.

## Anayasa maddeleri (seçme)

- Madde 1: Koli boşsa milletvekili oraya girer.
- Madde 2: Saat 03:17 kutsal saattir.
- Madde 3: İnsan yastığı kamulaştırılabilir.
- Madde 4: Bu maddeler tartışılamaz, sadece mırıldanılabilir.
